Anchor Memory Settings

记忆系统运行参数与上下文注入配置（所有配置持久化保存在本地 SQLite 的 anchor_settings 表中）

睡前对话余温衔接 (Bedtime Tail Bridge)

每天打烊复盘后，第二天唤醒时默认带有一段昨日摘要。开启此项后，系统会在昨日摘要下方，额外附带上昨晚临睡前的最后几条真实对话，保留交谈语境与情绪余温，使第二天的开场衔接更自然。

单日滚动对话压缩 (Daily Rolling Summary)

当某一天交谈轮次特别多、单日累积消息过长时，会大量占用模型窗口并增加消耗。开启此功能后，可以随时手动或由打烊流程触发压缩：系统从最早的未压缩原始消息提取摘要，与此前的滚动摘要合并，安全释放原始消息占用的上下文。

老记忆情绪增量补齐 (Backfill)

针对记忆库中从外部系统导入、或尚未标记情绪属性的历史记忆。开启后，系统在打烊批处理时，自动分析老记忆并补齐情绪愉悦度、激烈度和分类标签。若关闭，老记忆不会被修改，系统统一按 0.5 中立权重安全参与运算。

记忆主动搜索工具模式 (Search Tool Mode)

系统每轮对话都会根据语义向量、实体标签、情绪共振和时效衰减四个维度，在后台自动计算并向模型注入相关的长期记忆（此基础召回每轮自动自带）。此设置控制：当模型在交谈中觉得当前上下文信息不够用时，是否允许模型主动调用搜索工具去记忆库里二次搜索。

低权重沉底记忆管理 (Decay Archive)

记忆库中的条目会随时间自然衰减权重（重要度 $\ge 0.8$ 的核心记忆享有永久保护不会衰减）。长时间未被提及且重要度较低的记忆会沉到库底。你可以定期查看这些低权重记忆，并将其归档至 Obsidian 保管库 (Vault)，既能精简日常记忆库，又保证数据永远不会丢失。
